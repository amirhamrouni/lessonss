### What is adapted

The English Twin lesson-player state model borrows the general open-source interaction pattern of an active challenge index, selected answer, explicit idle / selected / wrong / correct states, progress advancement, and a persistent footer action. The implementation is ported to English Twin's React/Vite/Firebase architecture and expanded with multilingual support, visual vocabulary, browser TTS, adaptive mistakes, FSRS integration, and learner persistence.
