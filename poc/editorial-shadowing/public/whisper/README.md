# whisper.cpp local WASM assets

This POC deliberately does **not** commit generated WASM/model binaries.

Expected browser assets:

- `/whisper/libcommand.js` — generated by the official `ggml-org/whisper.cpp` Emscripten command example.
- `/whisper/ggml-tiny.en.bin` — local English model used by the POC.
- Any `.wasm` sidecar emitted by your Emscripten build should be copied into this same directory. `whisperWasm.ts` resolves sidecars through `/whisper/`.

The adapter in `lib/whisperWasm.ts` expects the official browser command API exposed by the generated module: `init`, `set_audio`, and `get_transcribed`.

Suggested build flow from the upstream whisper.cpp repository:

```bash
mkdir build-em && cd build-em
emcmake cmake ..
cmake --build . --config Release -j
```

Build the browser command/wasm example according to the current upstream README, then copy its generated `libcommand.js` (and `.wasm` when emitted separately) here. Copy a compatible tiny English model as `ggml-tiny.en.bin`.

The microphone recording remains local in the browser. No upload route is part of this POC.
